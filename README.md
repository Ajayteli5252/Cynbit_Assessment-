## 🌟 Executive Summary & Problem Statement

Cynbit Technologies (`cynbit.in`) is an elite software engineering and AI automation firm headquartered in Jaipur, Rajasthan.

When prospective clients visit **Cynbit's Inquiry Hub ("The Blueprint")** at `cynbit.in/contact`, they are greeted with a standard static contact form. 

### The Problem:
* **Zero Real-Time Feasibility:** Founders and CTOs visiting the site have no visibility into how long their project will take or what budget to expect before submitting.
* **Conversion Drop-Off:** Waiting 24 hours for basic sizing and scoping causes high-intent leads to drop off.
* **Missed Engineering Showcase:** A firm specializing in cutting-edge software architecture misses an opportunity to showcase interactive capability directly at its front door.

### The Proposed & Implemented Improvement:
We transformed **"The Blueprint."** section into an **Interactive System Scoper & Real-Time Estimation Engine** while maintaining 100% visual and brand fidelity to Cynbit's original website:
* **Exact UI Matching:** Replicates Cynbit's light mint/off-white theme, `(CYN ∞ BIT)` infinity logo, typography, pill buttons, `24H Response Sync` card, and `Global Delivery Hub` widget.
* **Interactive Scoping:** Clients select what they are building (*Autonomous AI Agents*, *Full-Stack SaaS*, *TenantEase PropTech*, *Cloud & DevOps*) and target scale (*MVP*, *Growth*, *Enterprise*).
* **Live Dynamic Sizing:** Instantly calculates estimated sprint timelines, budget brackets in USD ($) and INR (₹ Lakhs), and dedicated engineering pod composition.
* **One-Click Blueprint Proposal:** Directly generates a proposal with a print/PDF summary and logs the lead to the backend API.

## 🛠 Tech Stack

* **Framework:** Next.js 14+ (App Router)
* **Language:** TypeScript 5.6 (Strict Mode)
* **Styling:** Tailwind CSS (Custom Cynbit Forest Teal `#065457`, Mint `#0B6E6D`, and background `#FBFDFD`)
* **Icons & Feedback:** Lucide React & Canvas Confetti
* **Backend:** Next.js Route Handlers (`/api/blueprint`)

## 🚀 How to Run Locally

```bash
# 1. Clone repository
git clone https://github.com/<YOUR_GITHUB_USERNAME>/cynbit-interactive-hub.git
cd cynbit-interactive-hub

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open **`http://localhost:3000`** in your browser.
